# +180 Mapas Mentais de Matemática do Ensino Médio

Página de vendas profissional, moderna e de alta conversão para o infoproduto de Mapas Mentais de Fórmulas de Matemática do Ensino Médio.

## 🚀 Como Rodar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Gerar build de produção
npm run build
```

## 📦 Como Publicar no GitHub Pages

O projeto já está 100% configurado para o GitHub Pages:

1. Suba o código para o seu repositório no GitHub:
   ```bash
   git add .
   git commit -m "feat: landing page mapas mentais de matemática"
   git push origin main
   ```

2. No seu repositório no GitHub:
   - Vá em **Settings** > **Pages**.
   - Em **Build and deployment** > **Source**, selecione **GitHub Actions**.
   - O workflow `.github/workflows/deploy.yml` já incluso executará a compilação e publicação automática!

3. Sua página estará online no endereço: `https://seu-usuario.github.io/seu-repositorio/`

## ⚙️ Configurações Rápidas da Página
